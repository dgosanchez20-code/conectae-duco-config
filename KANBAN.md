# Tablero de Seguimiento y Gestión de Proyecto (Kanban) - Conecta-EduCo

## 1. Metodología de Gestión
Para el control y seguimiento de las actividades del proyecto **Conecta-EduCo**, se implementó un tablero bajo la metodología **Kanban**, estructurado para visualizar el flujo de trabajo en tiempo real, priorizar el backlog y asegurar el cumplimiento de los entregables del Paso 5 al Paso 7.

## 2. Estructura de Columnas del Tablero
El flujo de trabajo se divide en cuatro estados principales:

- **Backlog (Pendiente):** Tareas generales identificadas para la automatización, integración con la API de Wolkvox y documentación de calidad ISO/IEC 25010.
- **To Do (Por hacer):** Tareas priorizadas para el sprint o fase actual (ej. redacción de manuales, configuración de variables de entorno).
- **In Progress (En proceso):** Actividades actualmente en desarrollo o pruebas (ej. validación del código en Python y pruebas de conectividad con `HTTP 200 OK`).
- **Done (Completado):** Entregables finalizados, validados y subidos al repositorio oficial de GitHub (`conectae-duco-config`).
